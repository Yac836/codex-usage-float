# 回归测试

每次改动后运行：

```powershell
.\tests\run.ps1
```

脚本从源码构建应用、测试程序和模拟 Codex 服务。编译警告视为错误；失败返回非零结果。默认输出到系统临时目录，也可通过 `-OutputDirectory` 指定。`results.json` 记录每个场景、耗时、结果和总断言数，stdout/stderr 提供失败摘要。

测试不需要 Codex、不联网、不读取真实登录态、不修改用户偏好。所有设置和模拟进程文件位于测试输出目录。`circle-example.png` 使用模拟数据，供人工检查排版。

| 范围 | 自动检查 |
| --- | --- |
| 数据 | 两额度映射、缺失/真实 0、异常值、剩余换算、时间溢出、重置卡过滤与最早日期 |
| 设置 | 旧配置、类型错误、损坏/超大文件、合法范围、独立开关、原子保存 |
| RPC | 成功、后端错误、提前退出、初始化/读取超时、取消、噪声和大量通知 |
| 进程 | 正常退出、拒绝退出、子孙进程清理、强制结束所有者 |
| UI | 两种样式 × 8 种显示组合 × 3 种大小、透明边缘、日期/张数裁切、资源释放、异步刷新竞争和绘制失败回退 |
| 贴边 | 四边、负坐标、工作区内小条、悬停、菜单/拖动抑制、恢复与关闭开关 |
| 找回 | 单屏/移除屏幕/部分可见的几何修复、收起前尺寸、设置保留、原生热键冲突/释放/句柄重建与可见失败提示 |

在有交互桌面的 Windows 电脑追加：

```powershell
.\tests\run.ps1 -Desktop
```

该参数增加可见窗口的原生置顶、关闭置顶、模拟置顶状态丢失、焦点、句柄重建、透明度、收起与找回测试。另验证热键消息、托盘双击、显示/远程会话消息及自动修复不抢焦点。它会短暂显示测试窗口，全部使用模拟额度。原生注册测试使用 Ctrl+Alt+F24，避免占用用户实际 Ctrl+Alt+U；消息回归不能代替真实键盘和 RDP 会话切换检查。

每轮测试还会在输出目录生成 `preview-circle.png`、`preview-card.png`，由真实圆形绘制器和卡片控件渲染生成，使用模拟额度。人工检查后可更新 `docs/images/` 中的首页预览，禁止用真实账户或含桌面隐私的截图替代。

GitHub Actions 对 Windows runner 执行默认离线回归，检查公开文件清单后打包，再解压源码包到独立目录重新构建和回归。首次上传仓库后需要实际确认云端运行通过。托管 runner 的系统、字体和桌面环境不能代表全部用户的桌面；CI 通过不等于已验证鼠标操作、外观和不同应用覆盖关系。

发布前按 [REGRESSION_CHECKLIST.md](../REGRESSION_CHECKLIST.md) 逐项实机检查，记录系统、缩放、样式、结果和未验证项。系统缩放与窗口大小选项是两回事，三种窗口大小自动测试不能代替三种系统 DPI 实机检查。
