Codex Usage Float — Windows 便携版

开始使用
1. 把整个 ZIP 解压到一个文件夹。
2. 双击 CodexUsageFloat.exe，桌面会出现额度悬浮窗。
3. 拖动窗口调整位置，右键打开设置。
更新旧版本：先从窗口或托盘右键“退出”，再解压覆盖，偏好保留。

本机需要 Windows 10/11 64 位、.NET Framework 4.8，以及已安装并登录的 Codex。
本工具无需安装、编译或运行 PowerShell 脚本，也不需要填写 API Key。

常用操作
- 5小时、每周、重置卡：右键“显示项目”分别开启或隐藏。
- 圆形或卡片：右键“样式”切换。
- 贴边收起：拖到屏幕边缘，移开鼠标后收起，鼠标移入小条展开。
- 刷新：每分钟自动读取，双击窗口可立即刷新。
- 找回窗口：默认按 Ctrl+Alt+U，展开并居中到鼠标所在屏幕。
- 修改/关闭快捷键：右键“设置呼出快捷键…”，选择组合或取消启用，再保存。
- 托盘找回：双击任务栏右下角的蓝紫双环图标（可能在隐藏图标中）。
- 仍可再次双击 CodexUsageFloat.exe 找回，只保留一个实例。
- 退出：窗口或托盘图标右键选择“退出”。

远程桌面切为单屏、移除屏幕或分辨率变化后，会自动把窗口移回可见区域。
自动修复不抢占当前应用焦点；原先收起的小条会展开。
快捷键若被其他程序占用或注册失败，托盘会提示；可从右键菜单重试，或双击托盘找回。
修改快捷键失败时保留原绑定；关闭后保留最后键位，方便重新启用。
软件内部快捷键可能检测不到，影响常用软件时可换键或关闭。
远程桌面先获得键盘焦点；按键未传到远端时使用远端托盘。

重置卡只显示可用张数和最先到期日期，不会自动使用。悬停可查看已返回的明细。
如果提示找不到 Codex 或未登录，请先安装并打开本机 Codex 完成登录，再双击悬浮窗刷新。
